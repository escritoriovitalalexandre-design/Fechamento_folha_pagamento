Backup

Os dados ficam salvos no Supabase, e o sistema guarda versões automáticas (veja abaixo). Baixar um backup em arquivo continua sendo uma boa cópia extra.

Conteúdo atual dos dados salvos no navegador (uso técnico).

Versões salvas automaticamente

A cada gravação, o Supabase guarda a versão anterior (no máximo uma a cada 10 minutos). Ficam todas as versões dos últimos 7 dias e, depois, uma por dia até 90 dias. Para voltar a uma versão: baixe o arquivo dela e use ⬆️ Restaurar backup acima.

Migrar anexos antigos para o Storage

Documentos anexados antes da atualização de anexos (v3.2) ficaram gravados dentro dos dados do sistema, deixando tudo mais pesado. Use o botão abaixo para reenviá-los ao Supabase Storage — nada é apagado, só o armazenamento é trocado.
